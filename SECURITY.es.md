# Política de Seguridad

[English](./SECURITY.md) | **Español**

## Versiones compatibles

Actualmente, las correcciones de seguridad se evalúan para la versión publicada más reciente de FolderOrganizer.

| Versión | Soporte |
| --- | --- |
| 1.2.x | ✅ |
| < 1.2 | ❌ |

Se recomienda reproducir el problema de seguridad en la versión más reciente antes de reportarlo, siempre que hacerlo sea seguro.

## Reportar una vulnerabilidad

Por favor, **no abras un Issue público de GitHub** para reportar una posible vulnerabilidad.

Utiliza la función de reporte privado de vulnerabilidades de GitHub para este repositorio cuando esté disponible:

**Security → Report a vulnerability**

Incluye información suficiente para reproducir y evaluar el problema:

- versión afectada de FolderOrganizer;
- sistema operativo;
- si afecta a la ejecución interactiva, Windows Service, systemd o al instalador;
- pasos para reproducirlo;
- comportamiento esperado y observado;
- impacto potencial;
- logs o capturas con la información sensible eliminada.

No incluyas credenciales, tokens, datos personales ni contenido de archivos privados.

## Alcance

Son relevantes los reportes relacionados con operaciones sobre archivos, manejo de configuración, instalación o ejecución de servicios, comportamiento del instalador, manejo de rutas y vulnerabilidades relacionadas con dependencias.

Los reportes serán revisados antes de su divulgación pública. Por favor, concede un tiempo razonable para investigar y corregir el problema antes de publicar los detalles de la vulnerabilidad.
