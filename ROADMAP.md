# FolderOrganizer Roadmap

FolderOrganizer aims to remain a lightweight, reliable and easy-to-configure file automation tool.

## Now — v1.2.x

- Publish the stable Windows installer based on the validated v15 baseline.
- Improve update and configuration preservation.
- Expand troubleshooting and installation documentation.
- Collect bug reports and real-world feedback through GitHub Issues.
- Validate the Linux/systemd workflow on a clean Linux environment.

## Next

- Improve service status and diagnostics.
- Add clearer commands for installing, removing and checking the background service.
- Improve rule management and configuration editing.
- Add automated cross-platform tests where practical.
- Improve release artifacts and checksums.

## Later

- Multiple watched directories.
- More flexible matching rules beyond file extensions.
- Optional dry-run/preview mode.
- Import/export of FolderOrganizer configurations.
- Improved activity and organization logs.

## Support development

FolderOrganizer is independently maintained and released as open source.

If the project saves you time or is useful in your workflow, you can support continued maintenance through [GitHub Sponsors](https://github.com/sponsors/FrEaKAlL) or [Ko-fi](https://ko-fi.com/FrEaKAlL).

Feature priorities may change based on bug reports, community feedback and available maintenance time.
