# Security Policy

## Supported versions

Security fixes are currently evaluated for the latest published version of FolderOrganizer.

| Version | Supported |
| --- | --- |
| 1.2.x | ✅ |
| < 1.2 | ❌ |

Users are encouraged to reproduce a security issue on the latest release before reporting it when doing so is safe.

## Reporting a vulnerability

Please **do not open a public GitHub Issue** for a suspected vulnerability.

Use GitHub's private vulnerability reporting feature for this repository when it is available:

**Security → Report a vulnerability**

Include enough information to reproduce and assess the issue:

- affected FolderOrganizer version;
- operating system;
- whether the issue affects interactive execution, Windows Service, systemd, or the installer;
- steps to reproduce;
- expected and observed behavior;
- potential impact;
- logs or screenshots with sensitive information removed.

Please do not include credentials, tokens, personal data, or private file contents.

## Scope

Security reports related to file operations, configuration handling, service installation or execution, installer behavior, path handling, and dependency-related vulnerabilities are relevant to this project.

Reports will be reviewed before public disclosure. Please allow reasonable time for investigation and remediation before publishing vulnerability details.
